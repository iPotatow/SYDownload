# 界面设计审查与修订

采用 `redesign-existing-projects`、`build-macos-apps:swiftui-patterns` 和 `apple-design` 的审查方法。项目是 macOS SwiftUI 工具，保留系统字体、SF Symbols、原生表格、菜单与焦点反馈；没有套用网页字体、营销页面或装饰动画。

## 诊断与处理

| 问题 | 修订 |
| --- | --- |
| 侧栏、品牌与标题权重相近，导航间距偏大 | 侧栏 196 pt，品牌恢复原始 40 pt 图标、16 pt 字号与 56 pt 区域高度，导航行 32 pt；分为下载管理、照片工具，设置固定到底部 |
| 选中区需要保持克制 | 中性灰阶、StarBox 紫色强调与淡紫选中底色；侧栏使用系统 material；主 surface 保留圆角、阴影和上/右/下/左 8/8/8/0 pt 外边距 |
| 多种字号和对齐方式，页面像独立拼装 | 统一 20/14/13/12 字号层级与 24 pt 页面边距；筛选和设置分类与内容左边缘对齐 |
| EXIF 文件名、时间和状态缺少稳定列 | 原生 Table，勾选、文件、时间/结果列；长文件名与错误有悬停完整信息 |
| 修改预览纵向堆叠，占用过多高度 | 改为原始/处理后两列对照，随选中行更新 |
| EXIF 选项混在大卡片中 | 单独规则栏，按时间、格式、相机、保存分组；附加字段按选项展开 |
| 下载页有重复计数、状态框和分散操作 | 平台标识并入输入区标题，保存位置单独分组，状态与检查/下载动作同一操作行 |
| 历史/任务列表灰色底铺满空余区域 | 白色/深灰语义表面和轻边框；保留原生选择、搜索和右键操作 |
| 设置页更改按钮被压缩、说明冗长 | 保持按钮自然宽度；精简与选择相关的说明，收紧设置行高度 |

## 控件一致性修订

- 页面操作统一经过 CoreAction：13 pt 字号、系统 large 控件尺寸、至少 32 pt 的布局高度；主操作强调、次操作描边、辅助操作无边框，保留系统焦点与禁用反馈。
- 图标操作统一为 28 × 28 pt，14 pt 图标，统一中性色和悬停背景。
- 历史和任务的省略号菜单隐藏系统菜单箭头，避免两个符号挤在一起；下拉选择器保留其展开箭头。
- 恢复主 surface 明确规定的 8/8/8/0 pt 外边距。
- 应用外观改用原生 Picker，与同名文件策略、EXIF 规则下拉框保持一致。
- 控件修订后再次构建并通过严格签名检查和 git diff --check。实测历史顶部及行内菜单展开，下载按钮随输入启用/清空禁用，照片整理空态，设置外观下拉展开，EXIF 文件夹导入及全选/取消全选联动；未启动下载或写入照片。
- 本轮浅色截图已更新；深色截图保留上一轮状态，不代表本轮控件修订。

## 验证

- 使用 macOS 26.5 SDK 完成构建、打包与签名验证。
- 实际检查下载、任务、历史、照片整理、EXIF、通用设置页面。
- 下载输入：无效内容显示错误状态；合法小红书链接识别为 1 项，检查/下载按钮启用。清空测试输入，没有启动媒体下载。
- EXIF：生成图片目录的表格加载；勾选同步数量；选中 PNG 后对照更新；编号 64 在兼容模式下禁用并显示原因；相机品牌 Canon 连续输入保留焦点。
- EXIF 实际执行生成图片：成功 1 张、同名跳过 1 张、失败 0 张；没有修改用户照片。
- 深色模式通过仅本次启动有效的 `-preferredAppearance 深色` 参数检查；未改持久偏好。默认规则栏可完整显示，展开选项后可滚动。
- 没有创建 PR、推送或发布。没有重跑与视觉修改无关的完整测试套件；本机 `swift test` 的 XCTest 环境限制仍存在。

## StarBox 主题色

来源：[StarBox src/styles.css](https://github.com/iPotatow/StarBox/blob/main/src/styles.css) 的 `data-accent="violet"` 规则（读取于 2026-10-10）。OKLCH 转为 sRGB 后：

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 主色 | #764EC7 | #B199F4 |
| 选中底色 | #EFECFE | #231E31 |


统一作用于主操作、辅助链接、导航选中图标、勾选及焦点边框。中性表面、状态色和 surface 外边距保持既有定义。

原生强调按钮由系统调整填充及文字对比度；保留系统文字渲染。通过构建、严格签名检查与补丁格式检查，实测浅色和深色模式的按钮、链接、导航选区及输入焦点。启动参数仅本次生效，已恢复常规启动，未更改用户外观偏好。
