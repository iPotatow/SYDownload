# UI/UX 修订记录 · 2026-10-11

用户授权由实现方决定三个待选项后，采用以下行为：照片默认只扫描当前层，可勾选子文件夹；失败任务更换保存位置只影响该任务；EXIF 保留双栏工作区。

品牌名称、原始应用图标、侧栏品牌规格、紫色主题以及 surface 的 8/8/8/0 外边距均保留。

## 修订范围

- UX-01/02：EXIF 同目录刷新保留手动选择；计划绑定生成规则，取消后禁止执行旧计划，提供重新读取入口。
- UX-03/06/07/13：照片工作区由 AppModel 持有，切页保留目录和选择；目录与结果仅在扫描成功后一起替换；取消/失败恢复已提交的扫描范围；执行期间禁用日期勾选；递归选项明确提示包含输出和备份目录。
- UX-04：放弃设置恢复最近一次成功读取或保存的内存快照，不依赖再次访问引擎。初始读取失败显示“尚未读取配置”；无快照时保留未保存状态并说明无法回滚。
- UX-05：Bridge 通过进程文件锁串行执行共享引擎状态操作；下载请求携带固定 folderName，校验只观察所选目标子目录。排队等待不计入下载执行超时，取消进程后操作系统释放锁。下载期间的配置读写/检查返回明确 busy 提示，用户可在当前任务完成后重试。
- UX-08/09、UI-01：失败行收敛为紧凑处理菜单；登录/磁盘/链接恢复旁保留重试，支持完整错误悬停及复制；更换当前任务目录后直接重试，全局默认目录不变。
- UX-10/11/12：导入失败显示原因；仅有成功输出时提供打开结果；预览补齐 EXIF 创建、元数据修改、目标文件名和保存位置，说明不再混淆文件系统时间。
- UX-14：主场景使用唯一 Window，Cmd-N 显式打开该窗口再聚焦下载。实际验证关闭最后一个窗口会退出应用，无残留空壳；不把这个行为描述成已验证“关闭后仍在后台时 Cmd-N”。
- UI-02/03/04/05/06：EXIF 使用共享语义字体和面板圆角；操作符号继承控件字号；Cookie 标签只作用于输入；命名字段使用原生 checkbox 并给排序按钮标注字段名；搜索清除、排序和辅助动作使用共享控件。
- UI-07：选中侧栏项也绘制焦点边框。系统完整键盘导航矩阵仍待验证。

## 边界与取舍

为了保证共享配置和目录校验互不串账，本轮实际引擎下载串行，应用仍可以提交批次并显示等待。后续若恢复真实并行，应先让引擎配置和产物清单按任务隔离；不能直接删除锁。

没有进行真实联网下载、真实照片处理或删除、浏览器 Cookie 读取/保存、Sparkle 跨版本安装。仍未覆盖失败长错误行的全部窗口尺寸、大目录 GUI 取消、深色和所有辅助功能系统设置组合。目录快照校验不能辨认其他外部程序同时写入同一目录的文件。

全量阅读清单记录的是修订前快照，哈希不应视作修订后的文件哈希；原审查结论与证据保留作历史记录。
